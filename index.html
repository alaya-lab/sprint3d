TRELLIS.2-4B · 40-OBJECT SUBSET

The rebuilt mesh post-processing alone also speeds up TRELLIS.2, which uses the same GLB export code, by 6.7× without a detectable change in the evaluated metrics.

TRELLIS.2-4B at its released settings. Medians on the 40-object subset of the validation set; 95% confidence interval in brackets.
ConfigurationEnd-to-end time(s) ↓Post-processing(s) ↓Speed-up[95% CI]
TRELLIS.2 (official)112.791.4–
+ rebuilt mesh path16.92.26.7×[5.4, 8.6]

Only the mesh post-processing is carried over, not the flow engineering or the distilled students. The differences to TRELLIS.2 (official) in normal-map PSNR, mean angular error and base-color PSNR have confidence intervals that include zero, and a conservative estimate in the report still gives 5.7×. Running the mesh work concurrently with the texture flow does not save time in TRELLIS.2. The port wraps an unmodified TRELLIS.2 checkout; the commands are in the code repository.
